Resumen del proyecto: 

Este repositorio es una plantilla de aplicación React creada con Vite. Incluye la configuración mínima para arrancar una aplicación React con Hot Module Replacement (HMR) y reglas básicas de ESLint. Estructura principal detectada:
- index.html: punto de entrada HTML que carga /src/main.jsx
- src/: código fuente de la aplicación (vacío o con archivos de ejemplo dentro del repositorio)
- public/: recursos estáticos
- package.json / package-lock.json: dependencias y scripts
- vite.config.js: configuración de Vite

Qué hace el proyecto:
- Proporciona un esqueleto para desarrollar una SPA con React usando Vite como bundler y servidor de desarrollo.
- Facilita desarrollo rápido gracias a HMR y a una configuración mínima lista para comenzar.
